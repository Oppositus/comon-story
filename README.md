# Автоследование: исследование

Разбор российского рынка автоследования по полной популяции одной площадки — Comon (Финам): **19 978 стратегий, включая 18 529 закрытых**. Ни одна метрика не взята с витрины: всё пересчитано из дневных рядов доходности.

Автоследование — сервис, где инвестор подписывается на торговую стратегию другого человека, и сделки автора автоматически повторяются на его счёте. На витрине видно доходность, просадку, рейтинг и число подписчиков. Серия отвечает на вопрос, что эти числа значат — и чего по ним не видно.

## Устройство репозитория

```
md/        восемь файлов серии
images/    38 графиков, каждый порождён скриптом, который считает таблицу под ним
html/      те же тексты страницами: index.html + 8 глав + style.css
data/      расчётные наборы, из которых считаются все таблицы и графики
scripts/   код расчёта и сборки страниц
```

## Воспроизвести

Все числа серии считаются из `data/` — сырьё для этого не нужно:

```bash
pip install numpy pandas scipy scikit-learn matplotlib
cd scripts
python comon_author_tables.py    # главы 4-5: авторы, их попытки и результаты
python comon_selection.py        # отбор: что остаётся от популяции после фильтров
python comon_residual_life.py    # глава 2: сколько ещё проживёт дожившая стратегия
```

Каждый скрипт печатает таблицы в консоль и кладёт их в `results/`; с флагом `--charts` перерисовывает свои графики в `images/`. Страницы пересобираются командой `python build_html.py` (нужен `markdown`).

**Что считается сразу, а что нет.** Девять скриптов работают по готовым наборам из `data/`. Остальным нужны первичные ряды — дневная доходность и карточки всех стратегий, — а их в репозитории нет: это база данных площадки, и раздавать её копию мы не вправе. Такой скрипт не падает с невнятной ошибкой, а объясняет, чего именно не хватает.

Получить первичные данные можно тремя способами: собрать заново скриптом `scripts/comon_fetch.js`, запросить у автора нашу выгрузку или обойтись готовыми наборами. Подробно, вместе с правовым основанием, — в **[DATA.md](DATA.md)**.
